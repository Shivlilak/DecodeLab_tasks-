# Project 1 – Data Cleaning & Preparation

## Internship
DecodeLabs – Data Analytics Internship

## Project Overview

This project focuses on cleaning and preparing a raw dataset for further
data analysis. The main objective is to improve data quality by handling
missing values, duplicates, and incorrect data formats.

## Objectives

- Identify missing or null values
- Remove duplicate records
- Check for duplicate IDs
- Correct date and other data formats
- Prepare a reliable dataset for analysis

## Tools Used

- Microsoft Excel
- Python
- Pandas

## Data Cleaning Performed

- Identified missing values in the dataset
- Replaced missing values in the `CouponCode` column with `No Coupon`
- Checked and removed duplicate rows
- Checked for duplicate `OrderID` values
- Standardized the `Date` column
- Validated essential fields

## Final Data Quality

| Check | Result |
|---|---:|
| Total Records | 1,200 |
| Total Columns | 14 |
| Missing Values | 0 |
| Duplicate Rows | 0 |
| Duplicate Order IDs | 0 |
| Incorrect Dates | 0 |
